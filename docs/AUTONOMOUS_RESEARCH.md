# 本机自主研究运行器

## 使用

新建课题并添加已有研究资料，在研究概况选择“开始研究”，设置模型调用和实验次数上限。默认使用 ChatGPT、GPT-6.1 Sol、中等思考；模型不存在、登录失效或额度耗尽时停止，不切换模型。

目前支持本机 CPU 上的小规模 Python 数值研究：最多 5 条输入、1 个批次、种子 0、不训练；可使用 math、statistics、random 标准库。每次程序 CPU 上限 10 秒、墙钟上限 20 秒，父进程上限 30 秒，内存监测阈值 512 MB。没有安装依赖、下载模型、联网执行或 GPU/SSH 训练能力，不能将该范围描述为通用科研算力平台。

生成实验后，用户可查看代码与输入，确认冻结方案、选择本机、检查运行条件，随后“执行并继续研究”。执行器运行一次实验和一次同代码复现，两次均计入实验额度。这里的复现是另一个受限子进程重复执行同一冻结程序，清单记录 independent=false；不等同于独立实现或独立团队复现。后续分析、撰写和评审自动继续，下一份新代码再次经过确认。

## 流程

- 问题识别和核实 → 候选生成和依据检查。
- 基线实际运行及复现 → 候选小规模验证 → 完整授权数据范围验证；失败交给工程角色修订，保留失败记录。
- 按原状态机执行有限演化、候选选择、消融、方法修订与比较。
- 中文报告和完善 → 同行评审与评分核实 → 必要补充实验 → 综合评审和有限回流。
- I1–I4 核查。实际复现与文件证据完好、审计未要求补充实验时，最多允许一次报告修订并重新经过同行、综合评审和四项核查；旧拒绝意见永久保留。再次不通过则以核查失败结束。失败、无贡献、证据不足、预算耗尽均为真实结果，不强制生成“成功”。

已知问题模式把想法轮数和成功阈值设为 1；它用于验证执行链，不主张科研创新。消融结果持平且已有实际复现时，保留“未发现机制优势”的结论，继续撰写、评审与核查报告；最终状态为“已知问题验证通过”，与正式研究通过区分。常规创新研究仍要求机制贡献，不绕过贡献门槛。常规模式保留现有论文参数契约。完整实验仅覆盖已授权微型数据，不能把它冒充完整真实数据集评估。

## 持久化和约束

每步模型调用先持久化准入和预算，再调用模型；已完成的检查点可复用，未知结果不会静默重复调用。模型输入、资料上下文、角色输出、生成代码、数据、执行器、环境和指标按内容保存。后续角色还会收到通过哈希校验的实际执行清单，包括样本数、批次、种子与步数；失败尝试保留为失败证据，不能被当成成功依据，也不因如实披露失败而永久否定后续合规结果。运行记录、审计事件和派发清单在事务中提交。

暂停在步骤边界生效；取消撤销授权并中止当前任务。服务重启后只回收已有运行证据，缺少产物的已派发任务保持未知，不自动重复提交。无法恢复的未知任务仍需人工核对，不能宣称任意崩溃自动恢复。

实验在独立 Python 子进程及 macOS sandbox 中运行，禁止网络、子进程和用户文件读写；额外 AST 检查拒绝非批准模块和反射入口。资源限制和 AST 检查不是对任意恶意程序安全性的形式化证明。

I1 检查报告引用的实验与实际复现指标；I2 核对输入、环境和方案；I3 核对 DOI/标题、已导入原文摘录和独立角色的支持关系判断；I4 由独立角色对照保存代码及实际运行审计报告。模型评审不是客观正确性的保证，不能替代领域专家复核。没有原文支持的外部引用保持未确认并阻止正式导出。

## 验证状态

- 本地测试角色 + 真实受限 Python：六阶段端到端通过，包含 8 次极小运行，不属于单次连通性 Smoke Test。
- 模型预算耗尽、暂停持久化、重复派发/未确认门禁、禁止文件读取/系统模块导入已测试。
- 首次真实 GPT-6.1 Sol 中等思考调用成功，得到中文结构化返回；1 次硬上限生效。实际用量 16,910 tokens（输入 16,646，输出 264，其中推理 40）。
- 完整真实模型研究在修复后续跑完成：39 次调用，最终已知问题验证通过，I1–I4 通过，真实证据包导出及校验通过；加首次连通性共 40 次调用。开发介入、历史拒绝与具名证据补充完整记录于 `docs/VALIDATION.md`，不是首次无干预通过。
- 正式 Xcode build/test、XCUITest、公证分发、SSH、GPU/大规模实验及长期运行仍未验收。
