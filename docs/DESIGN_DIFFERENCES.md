## ScientistTwo 对照

公开论文依据：<https://arxiv.org/html/2609.19644v1>。参数契约位于 `specs/scientisttwo-paper-fidelity.json`。原始 `NORMA_Swift_Native_Architecture_v3.2.md` 保留不变，v3.3 开头的规范覆盖块记录新增决定；后续旧章节尚未逐项同步。

| 机制 | 当前代码 | 与正式目标的差距 |
| --- | --- | --- |
| 六阶段内部角色与反馈 | Role 枚举、ScientificWorkflow reducer、RoleRuntime、RoleCoordinator | 组件尚未接成服务可运行的完整科研编排；UI 阶段条不能证明六阶段已执行 |
| 局限/种子核验循环 | 局限 16 次，种子按目标池重复，预算耗尽为独立终态 | 尚缺真实文献检索、种子结构化输出和 novelty admission |
| 多轮想法、失败历史 | 4 轮、成功阈值 4、新种子与演化候选、历史完整性守卫 | 完整历史索引与真实候选生成未接通；不凭布尔值宣称实际证据完整 |
| Subset/Full-set/Engineer | good/engineer/bad 转移及工程重试上限 | 当前 Worker 仅能跑固定数值验证，不能运行任意科研代码或完整数据实验 |
| 消融与比较 | 归因门禁、一次修订、同协议严格改进 | 尚缺真实消融方案生成与执行；纯逻辑检查不等于科研归因成立 |
| Writer/Peer/Meta | 独立角色、两轮 peer、早停阈值 8、一次 meta 修订、不改进保留 prior best | 不使用原论文私有 PaperOrchestra/ScholarPeer；机制替代未完成真实联调 |
| I1/I2 | 本机五点实验真实独立复现、冻结输入和产物哈希关联 | 正式研究的完整复现协议、候选级 I2 审核待接入 |
| I3 | DOI/标题查询组件，明确存在性不等于论据支持 | 未接入正文引用核查及有界修复；本轮未执行网络查询 |
| I4 | 角色/门禁契约 | 代码与论文方法的一致性审计、修复和复查未实现 |
| 自主运行 | 研究授权、模型预算、执行门禁契约 | 当前入口只允许零模型预算本机验证；完整课题级自主授权、衍生计划授权待接通 |

`seedCount=2`、`initialCandidateCount=1` 是 NORMA 开发默认值，不冒充原论文未公开的 N_seed/N0。种子循环不再错误复用局限提取的 16 次上限；它应受课题预算约束。

## 外部验收条件

1. 用户亲自处理 Xcode 许可，随后运行工程 list/build/test 和 UI Tests。
2. 用户醒来后明确真实模型调用预算，再验证 `gpt-6.1-sol` / `medium`。
3. 后续需要远端验收时，由用户提供 SSH 地址、端口、用户名、授权目录与现有环境；不能把当前“仅本机”授权扩展成远端连接。
4. 正式分发签名、公证和正式发布尚未进行。

上述条件之外的实现缺口仍属工程待办，不能全部归因于账户或许可阻塞。
